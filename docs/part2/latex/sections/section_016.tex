The table lists one event per row, using the textbook classification: \textbf{external} events start outside the system (an actor does something), \textbf{temporal} events are triggered by reaching a point in time, and \textbf{state} events happen when something inside the system changes and triggers further processing. The system operation names in brackets are the SSD messages in section 2.2. The table has 27 external, 2 temporal and 3 state events.
