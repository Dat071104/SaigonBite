The 12 lifecycle rows use the exact operation names in plan \S{}4. They are \textbf{External} events because an actor command triggers each change; the new state is the response, not an autonomous state-event handler. Voucher date boundaries are temporal conditions checked on demand. No scheduler, independent state-event handler or database actor is assumed.
