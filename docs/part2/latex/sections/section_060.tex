\textbf{Presentation adapter and resources}

The \texttt{order} / \texttt{kitchen} identifiers are actual Flask blueprint modules (\texttt{saigonbite/\allowbreak{}presentation/\allowbreak{}blueprints/\allowbreak{}*.\allowbreak{}py}); each route remains its actual Python function and HTTP rule. The SSD operation is translated at this boundary; session identity and route/form fields supply the controller arguments.

Templates used by the selected blueprint module(s): \texttt{order/\allowbreak{}confirmation.\allowbreak{}html}, \texttt{order/\allowbreak{}detail.\allowbreak{}html}, \texttt{order/\allowbreak{}hubs.\allowbreak{}html}, \texttt{order/\allowbreak{}menu.\allowbreak{}html}, \texttt{order/\allowbreak{}my\_\allowbreak{}orders.\allowbreak{}html}, \texttt{order/\allowbreak{}payment\_\allowbreak{}simulator.\allowbreak{}html}, \texttt{order/\allowbreak{}quote.\allowbreak{}html}.

Non-persisted values include Quote, PaymentChoice, HubStatus, response dataclasses and Authorisation. Busy/quiet are derived properties; no Busy/Quiet enum is introduced. No refund payout is designed.
