\textbf{Privacy and assignment boundary}

Shipper-facing DeliveryView contains only the permitted contact and stored address snapshot. Customer.passport\_no is not part of the shipper projection. The Delivery-to-UserAccount association carries the optional assigned-shipper role; no shipper class is fabricated.

\textbf{Architecture correspondence}

Actual DAO imports of domain values remain static couplings in these CRC collaborators; they are an upward-dependency P4.9 finding documented in section 4.2, and are not drawn as permitted dependencies in the layered DCD.
