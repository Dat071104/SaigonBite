\textbf{Presentation adapter and resources}

The \texttt{order} / \texttt{kitchen} identifiers are actual Flask blueprint modules (\texttt{saigonbite/presentation/blueprints/*.py}); each route remains its actual Python function and HTTP rule. The SSD operation is translated at this boundary; session identity and route/form fields supply the controller arguments.

Templates used by the selected blueprint module(s): \texttt{order/confirmation.html}, \texttt{order/detail.html}, \texttt{order/hubs.html}, \texttt{order/menu.html}, \texttt{order/my\_orders.html}, \texttt{order/payment\_simulator.html}, \texttt{order/quote.html}.

Non-persisted values include Quote, PaymentChoice, HubStatus, response dataclasses and Authorisation. Busy/quiet are derived properties; no Busy/Quiet enum is introduced. No refund payout is designed.
