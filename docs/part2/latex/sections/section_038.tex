\textbf{UC-04 --- Produce management reports: sales, workload, delivery performance (author: 722I0004)}

Author: 722I0004 \ensuremath{\cdot} AI-assisted (Codex)

\textbf{Use case name}

UC-04 --- Produce management reports: sales, workload, delivery performance.

\textbf{Scenario / trigger}

A manager asks for operational sales for Vietnam calendar dates, the current hub workload, or delivery performance. Reports read shared records; no Report entity or lifecycle is created. Main flow is sales; A01/A02 cover the other report requests.

\textbf{Actors}

Primary: Manager with an authenticated ACTIVE MANAGER account. Other roles, including Admin, are denied these operations. No database, clock, controller or report object is an actor.

\textbf{Related use cases}

Figure 2.1C associates Manager with UC-04 and has no UC-04 include/extend relation. UC-01/02/05 and SUC-05 supply Order, Payment and Delivery facts; UC-03 supplies hubs; SUC-09 preserves archived history for reporting; SUC-01 supplies authentication. These are serving/data references only.

\textbf{Stakeholders and interests}

Manager needs comparable definitions, visible filters, sample sizes and honest empty outcomes. Client needs workload for staffing and delivery trends. Customers and management need retained archived history and refunds owed reported separately without double subtraction. Data owners need a read-only operation with no accidental archive or lifecycle changes.

\textbf{Pre-conditions}

Each report request rechecks the session's active MANAGER role. Order/OrderLine, Payment, Delivery and Hub facts follow their owning contracts; an empty data set is valid. Sales/performance requests require valid \texttt{startDateVN}, \texttt{endDateVN}, start\ensuremath{\leq}end and, if supplied, an existing \texttt{hubId} (archived hubs are permitted historical filters). The workload request takes no dates or hub parameter; it is the current per-hub snapshot labelled ``now.'' Defaults are team assumptions pending Q5, never recorded as client approval.

Calculation definitions are part of the required response. Order totals remain T=S\ensuremath{-}D+F\ensuremath{-}Q. Refunds owed is a separate column of obligations for the selected delivered orders, not a second reduction of operational sales; this report does not pretend to be a global refund ledger. Workload has no historic period and does not reinterpret archived history as new work. The hand oracle must independently apply the same filter, grain and formulas in later verification; none is measured here.
