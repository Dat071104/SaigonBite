HubMenuItem is the shared-model association class of Hub and MenuItem. Its independent is\_available belongs to one pair. The approved logical MenuController collaborator is deliberately distinguished from a direct Python call target.

The existing admin route functions catalogue/hub\_menu/list\_item remain marked behavioral targets for the wrapper/initial-availability adapters (P2-S14/P2-S15); symbol existence does not clear those obligations.
