\textbf{Deployment plan}

The system is deployed as one Docker Compose application on one Google Cloud virtual machine. The same Compose files run on a laptop, so a reviewer can start the identical release locally. The public site is \LinkDeployed (fallback \LinkDeployedFallback).

\textbf{Instructions}

\textbf{A. Run locally with Docker (recommended for reviewers).} Requires Git and Docker Desktop.

\begin{lstlisting}
git clone https://github.com/Dat071104/SaigonBite.git
cd SaigonBite
git checkout v0.9-part2
docker compose up --build -d
\end{lstlisting}
Open http://127.0.0.1:5000. The database is created and seeded on the first start and kept in a Docker volume. Stop with \texttt{docker compose down}; \texttt{docker compose down -v} also deletes the local demo database so that the next start reseeds it.

\textbf{B. Run locally without Docker.} Requires Python 3.13.

\begin{lstlisting}
python -m venv .venv
.venv\Scripts\activate          (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python init_db.py
flask --app app run
\end{lstlisting}
\texttt{init\_\allowbreak{}db.\allowbreak{}py} creates \texttt{instance/\allowbreak{}saigonbite.\allowbreak{}db} with the schema, seed data and demo history; the tests are run with \texttt{python -m pytest -q} (5.1).

\textbf{C. Deploy to the VM.} The operator runbook \texttt{deploy/\allowbreak{}RUNBOOK.\allowbreak{}md} gives every command. In short: create the VM, static IP, firewall rules and storage bucket; copy the release bundle to the VM over IAP; run \texttt{deploy/\allowbreak{}vm\_\allowbreak{}setup.\allowbreak{}sh \textless{}hostname\textgreater{}} once (installs Docker, creates the directories and the secret, enables the backup timer) and \texttt{deploy/\allowbreak{}deploy.\allowbreak{}sh \textless{}tag\textgreater{} \textless{}bundle\textgreater{}} for each release (builds the image, starts Compose, waits for HTTPS, keeps the previous release for rollback). \texttt{deploy/\allowbreak{}restore.\allowbreak{}sh} restores a backup into a separate check path; \texttt{deploy/\allowbreak{}reset\_\allowbreak{}demo.\allowbreak{}sh --confirm-reset} resets the demo data after taking a backup.
