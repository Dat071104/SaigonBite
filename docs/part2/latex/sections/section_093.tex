\textbf{F-09 identity and presentation target}

ReportDAO.top\_items retains menu\_item\_id in grouping and read rows. SalesReport.top\_items carries list[tuple[int, str, int, int]] (item ID, snapshot name, quantity, revenue). reports.sales and its template preserve that identity when rendering; these three elements are C0 design target (final status in Table P4-1) under F-09 / P4.8. No target behavior is claimed executed.
